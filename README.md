# Simulação Ética de Phishing — SIGA CPS

Este projeto consiste no desenvolvimento de uma página web que simula a interface de autenticação do **SIGA (Sistema Integrado de Gestão Acadêmica) do Centro Paula Souza (CPS)**.

A aplicação foi desenvolvida **exclusivamente para fins acadêmicos e de pesquisa em segurança da informação**, com o objetivo de possibilitar estudos relacionados a phishing, detecção de páginas fraudulentas e mecanismos de proteção em ambientes web.

## Aviso

Este projeto é uma **simulação controlada de phishing**.

A página **não é utilizada para obtenção de credenciais, informações pessoais ou qualquer outro dado de terceiros**.

O projeto não possui vínculo oficial com o **Centro Paula Souza (CPS)**, **FATEC**, **ETEC** ou com o sistema **SIGA**. Nomes, marcas e elementos visuais eventualmente utilizados pertencem aos seus respectivos proprietários e são empregados apenas como referência no contexto acadêmico da pesquisa.

**Uso exclusivamente educacional, acadêmico e de pesquisa em segurança da informação.**

Este repositório não fornece autorização para utilização da página contra usuários ou sistemas reais.
